Here is the link for the dataset we use: https://www.kaggle.com/datasets/algozee/student
It contains information and description of the dataset.

I also uploaded the raw data in a separate branch called "student_performance.csv".

Below is a walkthrough of our project and how to use our codes:

1. Part 1 is the part which we performed an EDA and you can simply run "Part 1 code.py" to get the results.
It will generate the same results and plots that you are going to see in the jupyter notebook which noted as "Part 1 plot.ipynb"

2. Part 2 is mainly about our trained models and you can run the "Part 2 plot.ipynb "notebook.
It will automatically import functions from "Part 2 code.py" to process the data before proceeding to training and SHAP analysis.

3. You will also find there is a zipped file which contains the serialized pre-trained models in .pkl format from part 2.

4. There are two .pdf documents named "143 Part 1" and "143 Part 2" which shows the detail of how we finished this project.
We put some of them in our presentation, however, if you want to know more, feel free to check those documents.

PS: Please dowanload the csv file and change the file directory on your computer if you want to run our code(We also add comments about this in our raw codes)
